# 建立与复用本地笔迹档案

在用户授权的本地工作区中，将真实样本与已认可习惯保存到 `private/handwriting/<profile-id>/` 等明确目录；先检查宿主项目规则，不写系统或全局配置。不要把资料保存在公共Skill包内。

档案至少记录：

- 样本路径与来源；区分真实手写、生成候选和已验收生成页。
- 具体字形特点、数字/数学符号写法、笔画、字距、行距、版面与曲线习惯。
- 默认输出、纸张和页眉是否可复用；敏感身份字段仅在本次授权范围内使用。
- 用户反馈、已接受/拒绝的例子，以及相似度是否经过本人验收。

不要将某位用户偏好推广为所有人的默认值。自然工整、潦草、划改程度分别按本人要求处理；不能仅增加抖动就声称更像本人。

选择清晰且具有代表性的样本，关注中文、数字、拉丁/希腊字母及数学符号覆盖。样本不足时指出缺什么，而不是要求无目的地大量上传。

后续任务能读取该档案时自动复用。本次上传及明确要求优先。档案持久化不等于训练模型；生成页不能混成真实训练样本。

公开发布前只提交Skill、脚本和说明，不提交 `private/`、真实样本、姓名学号、密钥或含身份的成品截图。
